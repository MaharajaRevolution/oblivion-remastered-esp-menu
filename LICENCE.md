## 🧩 About

**Oblivion Remastered Companion** is a curated list of Oblivion Remastered open-source tools:

- **Overlays** — on-screen helpers, layout notes, entity viewer, quest tracker
- **Quality-of-Life Helpers** — inventory catalog, gear manager, overlay notes
- **Research Notes** — exploration layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Exploration Helpers
- Quest Tracker — follow main and side quests from the overlay
- Entity Viewer — visualize nearby creatures and NPCs
- Map Notes — mark points of interest and fast-travel spots
- Time Scale — adjust in-game time for study (0.1x to 5x)

### 🎨 Catalog & Cosmetics
- Item Catalog — browse weapons, armor, potions, spells
- Custom Gear Notes — organize player equipment sets
- Enhanced Compass — improved navigation visibility

### 🏋️ Practice Layout
- Save State Notes — segment study on any layout
- Camera Control — manually adjust view angles mid-play
- Movement Buffer Notes — chain complex maneuvers in the editor
